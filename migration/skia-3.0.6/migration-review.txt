Version selection:
Skia 3.0.6 ships Graphite 154.1.0 with dawn-chrome-m154a; WebGPU 0.12.1 declares chrome-m154a.
Skia 3.0.5 and 3.0.6 have identical published source files; only package.json differs.

Do not mix the tags or bypass the podspec alignment check.

Implementation:
1. MakeFromNativeTexture and MakeImageFromNativeTexture become MakeFromGPUTexture and MakeImageFromGPUTexture; pass the GPUTexture object.
2. Native MakeImageFromNativeBuffer no longer exists. On the main RN runtime capture the shared device and RNWebGPU NativeObject. Their supported native serializers carry them to worklets. Do not assume installWebGPU creates a worklet global RNWebGPU.
3. Wrap the decoder CVPixelBuffer with NativeVideoFrame, then WebGPU copyExternalImageToTexture into one reusable BGRA scratch texture per consuming runtime. Keep orientation unchanged; drawVideoFrame rotates once.
4. Draw that scratch into the existing Skia staging surface, take an immutable snapshot, wait for checked GPU completion, dispose the borrowed SkImage, release the extra native wrapper, then release the original decoder lease.
5. Native wrapper/decoder leases and reservations survive failures to drain. New imports are blocked until cleanup succeeds. Retrying the same pending frame cannot release its original decoder reservation early.
6. The small version/hash-gated Skia patch keeps canvas disposal and snapshot-null protection, and adds enableCheckedSubmissions() on an individual surface. getVideoCanvas opts in; generic app surfaces do not change. Only opted-in flush/snapshot calls use the helper that rejects snap failure, insert failure, and submit failure. Empty valid recordings are accepted. Raster surfaces cannot pretend to provide a GPU completion fence.
7. Export remains synchronous readback into the bounded native encoder pool. No zero-copy export change. Public copy/direct preferences retain compatibility semantics.
8. Native backend diagnostics identify the additional WebGPU blit and scratch capacity.

Memory/performance limits:
There are THREE full-frame GPU writes in the native import route: native-frame blit -> staging draw -> immutable snapshot. This adds one pass and one scratch texture compared with 3.0.3. A 3840x2160 BGRA scratch is 31.64 MiB, per active consuming runtime, excluding driver padding. The texture is reserved before allocation, reused at equal size, and explicitly destroyed after completion on cleanup/resize. Cached owned snapshots remain bounded at 32 producers; native decoder capacity is unchanged. No claim of better memory, latency, battery, or true direct/zero-copy is justified before new physical measurements.
